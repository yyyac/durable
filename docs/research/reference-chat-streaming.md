# 参考工作台的纯聊天与流式展示观察

观察日期：2026-11-05。参考站：`http://127.0.0.1:58766/`。在独立测试会话中进行了两轮纯聊天，保持 GLM-5.3-Flash / High 与原有全局设置；未调用工具，未修改设置或已有会话。测试会话地址：`http://127.0.0.1:58766/sessions/session_deec242d-dcc7-4723-b4d4-db8f2a2781d7`。

## 实际观察

| 阶段 | 可见行为 |
| --- | --- |
| 刚发送 | 首次创建时显示“正在创建对话…”，随后显示“请求中…”。 |
| 思考生成 | 思考区域默认折叠，标题为“思考中…”并显示秒数；同时有“工作中…”状态及中断按钮。 |
| 思考结束 | 标题变为“思考过程 · Ns”，仍折叠。 |
| 正文生成 | 正文按片段增长，即时渲染 Markdown；流式期间可能短暂显示尚未闭合的格式标记。 |
| 回合完成 | 中断按钮消失，恢复普通输入提示，显示时间戳与复制按钮，思考保留耗时且仍折叠。 |

- 思考内容在状态中按片段追加。本次没有实际在生成期间手动展开，不能据此声称已观察展开后的滚动行为。
- 两轮输出均为先思考、后正文；不能推断其它模型必然不交错输出。
- 正文包含引用、列表及加粗时会即时转换为对应 Markdown 结构。
- 聊天处于跟随状态时，正文增长会使页面向下滚动；未测试手动向上滚动后的跟随规则。
- 参考站生成期间支持排队输入与 `Ctrl+S` 插入回合，未实际测试。这与本项目已确认的“同一会话生成时禁止重复发送”不同，不能直接照搬。

## 与已确认方案的差异

此前讨论暂定“生成期间展开思考，完成后自动折叠”。实际观察表明，参考站在当前配置下思考全程默认折叠，未发生自动展开或折叠过渡。用户已在 2026-11-05 确认按原站复刻：思考默认折叠，点击展开查看，保留生成状态与耗时显示；此前暂定规则已被替代。
