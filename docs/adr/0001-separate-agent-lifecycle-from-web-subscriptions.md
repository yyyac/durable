# Agent 任务生命周期与网页订阅分离

工作台需要在切换会话、刷新或关闭页面后继续生成，并在重新打开时恢复显示。因此由常驻 Node 后端持有 pi-durable Harness，运行时管理会话、任务与持久化状态；网页连接只负责观察。停止生成必须通过明确的命令接口，订阅断开只清理观察，不取消任务。

前后端采用 REST 命令与 SSE 状态订阅：当前交互主要是离散命令和后端到前端的持续更新，使用独立的命令请求与单向状态流即可表达。相比 WebSocket，这一选择使命令与订阅的职责更直接；两种传输都无法代替后端的任务生命周期管理。每次重连先同步当前状态，再发送后续更新，不依赖浏览器保存完整流式记录。
