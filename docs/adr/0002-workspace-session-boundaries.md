# 工作区共享文件，会话独立保存上下文和归属

工作台在普通聊天之外增加绑定本机目录的工作区；同一实际目录对应一个工作区，其会话共享目录中的文件，各自保留独立的聊天上下文。会话创建后固定工作区归属，原有会话保持为普通会话，以避免将已有上下文中的路径和操作意图带到另一目录。

聊天记录和运行状态继续统一保存在工作台的数据目录中，工作区目录承载用户文件，不自动写入会话数据库或隐藏配置。与随项目保存会话的方案相比，这保持了项目文件和私人聊天记录的边界，但复制项目不会同时复制会话历史。

目录移动后的重新定位保留工作区身份及会话归属，只改变目录关联；重新定位前先停止运行中和待确认的任务，由用户确认新旧路径，不把旧工具调用直接带入新路径执行。
