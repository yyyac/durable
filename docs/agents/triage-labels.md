# Triage 标签

各技能以五个规范的 triage 角色进行沟通。本文件将这些角色映射到本仓库议题跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本跟踪器中的标签 | 含义                                     |
| -------------------------- | ---------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`   | 维护者需要评估该议题                     |
| `needs-info`               | `needs-info`     | 等待报告者补充更多信息                   |
| `ready-for-agent`          | `ready-for-agent` | 规格完备，可交给 AFK agent 实现          |
| `ready-for-human`          | `ready-for-human` | 需要人工实现                             |
| `wontfix`                  | `wontfix`        | 不予处理                                 |

当技能提到某个角色（例如「打上 AFK-ready triage 标签」）时，使用本表中对应的标签字符串。

如实际使用的词汇不同，直接修改「本跟踪器中的标签」一列即可。
